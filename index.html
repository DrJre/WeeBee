Admin ADMIN

🔒 Maintenance Mode
Locks out all non-admin users immediately. Admins can still sign in.
⚠️ User Moderation
Search for a user to ban, set ban duration, or permanently nuke their account and data.
🕵️ Alt Account Scanner
Groups accounts that share a device fingerprint (captured at account creation). Shows trade history between flagged accounts and a risk score. Use as a starting point — check the details before acting.
⚖️ Lopsided Trade Scanner
Flags accounts that have received free cards or amber (other side gave nothing). Especially suspicious when the same donor repeats this pattern — common sign of alt-account resource draining.
📋 Trade Log
All trades across all users — click any row to see full details.

Click Refresh to load trades.

⏪ Trade Reversal Tool
Find all completed trades sent by a user and delete the cards they sent from recipients' collections. Paste the sender's UID (found in the trade log detail modal).
🔧 Repair Unsettled Auctions
Settles expired auctions stuck in queued, live, or settling status — sends cards to winners, returns unsold items to sellers.
📬 Repair Undelivered Won Auctions
Finds 'won' listings where the winner never received their card and queues delivery — winners get their card automatically next time they open the TCG.
✏️ Fix Profile Display Name
Override the Firestore displayName for any user — useful when it got reset to "WeeBee User" by a past bug.

📦 Force-Deliver Won Auction
For auctions stuck in 'won' status where the card was never actually delivered. Paste the Firestore listing ID and hit Deliver.
🛠️ Repair Bulletin Trade
For trades where the listing owner got their cards but the offeror didn't. Paste the bulletin_offers doc ID from Firestore. Each broken offer needs to be repaired separately.
🧹 Deduplicate Bulletin Listings
Finds cards listed more than once on the bulletin board and withdraws all but the newest listing for each card.
🎉 Pack Store Flash Sale
Rolls pack prices back to their sale price. Stays active until toggled off.
📦 Filler Pack (Flex Slot)
Shown in store slot 5 when no event is running. Set the batch number to pull cards from.
🟡 Amber Wallet
Live balances and full amber transaction log.

Click Refresh to load wallet data.

💳 Stripe Purchase History
Look up all Amber purchases a user has made via Stripe. Paste their WeeBee UID.
➕ Send Amber to User
Refund or compensate a user — e.g. accidental duplicate pack purchases.
➖ Deduct Amber from User
Claw back amber from exploit payouts. Balance will not go below 0.
✨ Card Generator
🌱 Card Pool Seeder
Fetches top 100 anime → top 30 chars each → saves to Firestore with rarity tags. Takes ~60s.
➕ Add Anime to Pool
Search for any anime and add its top 30 characters as Rare/Common cards. Narrators are filtered automatically.
🎨 Sync Hand-Curated SR/SSR/UR Art
Copies hand-curated cards into the pool so they're searchable and editable. Safe to re-run.
✦ Seed Neon 2026 Cards (NR)
Writes TCG_EVENT_PREVIEW_CARDS to Firestore as rarityTier:nr with neon color metadata. Run before starting the event. Safe to re-run.
📊 Pool Capacity
Serial slots remaining per rarity. Red = running low.
🖼️ Validate Card Images
Test-loads every card's image. Failed images are flagged and excluded from pack pulls.
🗑️ Remove Duplicate Cards
Scans every collection for cards with the same name, rarity, and serial. Keeps earliest copy.
🔍 Cross-User Serial Dupe Scanner
Finds cards where two+ users own the same serial. You pick which copy to delete per card.

Starts the 7-day Prismatic Pack window. When active, it takes the flex slot (slot 5) in the store.

Current event card designs with neon borders. Update TCG_EVENT_PREVIEW_CARDS in app.js to swap in new samples.
